# FlowPilot — Project Vision

> Single source of truth for product identity and non-negotiables. Read this
> file before any development work. Last updated: PROMPT-ARCH-01.

## What FlowPilot Is

**FlowPilot is a WhatsApp Appointment Conversion System.**

It turns inbound WhatsApp conversations into confirmed, attended appointments —
automatically where possible, with a human in the loop where it matters.

**WhatsApp-first.** WhatsApp is the current product channel; additional
channels are future possibilities only — FlowPilot does not become an
omnichannel platform.

## Product Mission

Help small appointment-based businesses stop losing revenue from unanswered
messages, slow replies, and no-shows — by converting WhatsApp conversations
into booked, confirmed, and completed appointments.

## Current Stage

**Local Vertical Discovery Strategy.**

The same generic booking engine is deployed to real businesses across several
appointment-driven verticals (dental, beauty, coaching, gyms, education,
services) to discover which vertical produces the strongest willingness to pay.

The UI, domain model, and copy must remain **completely vertical-agnostic**.

## Target Users

- Owners/operators of small appointment-based businesses
- Non-technical; primarily mobile users; Arabic-speaking
- Manage bookings today via WhatsApp manually

## Target Market

- **Now:** Kafr El Sheikh, Egypt (local, walk-in relationships)
- **Later:** similar cities; then verticalized national expansion

## Core Value Proposition

> "Book more, chase less."

1. Every WhatsApp inquiry gets an instant, accurate reply.
2. Bookings happen inside the conversation without back-and-forth.
3. No-shows drop through automated confirmation and reminders.
4. The owner sees everything in one calm dashboard.

## What FlowPilot Is NOT

FlowPilot is **not**:

| Not this                  | Why                                                                 |
| ------------------------- | ------------------------------------------------------------------- |
| A CRM                     | We do not manage sales pipelines or leads beyond booking flows.     |
| An ERP                    | No inventory, accounting, HR, or operations modules.                |
| A POS                     | No point-of-sale, checkout, or payment processing.                  |
| A Marketing Platform      | No campaigns, broadcasts funnels, or ad tooling.                    |
| A Marketplace             | We are not a directory connecting customers to businesses.          |
| A General Chatbot Builder | AI exists only for appointment conversion, not arbitrary bots.      |
| An Enterprise Platform    | No roles engines, org charts, SSO, or governance — not prematurely. |
| An Omnichannel Platform   | WhatsApp-first; the channel boundary stays thin.                    |

If a proposed feature drifts toward any of the above, reject it or escalate
for an explicit scope decision.

## Current Goal: Local Vertical Discovery Strategy

Deploy one identical engine across multiple local verticals and measure which
one converts into durable revenue.

### Success IS measured by

- **Paid pilots** (businesses paying real money)
- **Renewals** (second month paid, unprompted)
- **Willingness to pay** (price acceptance without heavy discounting)
- **Measurable ROI** (e.g., recovered bookings per month vs. cost)

### Success is NOT measured by

- Signups
- Demo requests
- Feature requests
- App downloads
- Positive verbal feedback ("nice idea")

## Non-Negotiables

1. Arabic-first, RTL-first product experience.
2. Human-in-the-loop: AI never fully replaces human judgment for bookings.
3. Vertical-agnostic until a winning vertical is chosen.
4. Revenue evidence over vanity metrics.
