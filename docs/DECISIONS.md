| 24  | PROMPT-05 | **ADMIN account activation consistency model (binding):** One-time activation is represented by `Invitation.activatedAt` (nullable timestamp, set exactly once by the atomic conditional guard in `InvitationRepository.activateInvitedAdmin` — the smallest additive schema change; no status enum, consistent with the derived lifecycle). Better Auth identity creation (`auth.api.signUpEmail` behind an injectable dependency) and the FlowPilot domain write (invitation mark + Business ADMIN membership in ONE Prisma transaction) are two sequential atomic phases — no shared transaction is attempted (not supported through the installed Better Auth version's public API; distributed transactions/sagas/queues are forbidden by ARCHITECTURE).
