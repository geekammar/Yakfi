# FlowPilot — Integration Checkpoints

> **ONE canonical place for external-provider integration holds.** Each
> entry is a single, dated checkpoint for one external integration whose
> completion boundary is owned by an outside party (Meta, an AI provider,
> …). A checkpoint records where FlowPilot demonstrably stopped, what
> remained inside the external party's own surface, and the exact
> condition under which the work may resume — so no agent ever silently
> reopens it during unrelated work.
>
> Reading policy: Tier 1. Load this file only when a prompt touches one of
> the named integrations. There is exactly ONE checkpoint per integration.
>
> Related: `docs/DECISIONS.md` (append-only decisions), `docs/BUILD_STATE.md`
> (implementation ledger), `docs/AGENT_RULES.md` (tier model).
